# Dashboard: interactive presentation layer

A Next.js app, built on the supplied Estate/Next.js UI template, that presents the R practical-exam
analysis. It displays **only** files generated by the R project. It does no statistical calculation
of its own, so it cannot disagree with the report.

```
main_analysis.R / build_report.R  ──writes──▶  frontend/public/project/*  ──read by──▶  this app
```

## Run

```bash
npm install
npm run dev        # http://localhost:3000
```

Production: `npm run build`, then `npm run start`. The page reads the R outputs on each request
(`dynamic = "force-dynamic"`), so re-running the R analysis updates the dashboard without a rebuild.

If the data files are missing, the page shows what is missing and how to regenerate it, rather
than showing empty or invented numbers. To regenerate, run `Rscript build_report.R` in the
project folder.

## Sections

Overview · data pipeline · key indicators · the four required figures (plus the diagnostic figure,
with a full-screen view) · advanced analysis (correlation, regression, ANOVA and Welch's ANOVA,
outliers, sensitivity, group tables, Section A) · country explorer (search, income and region
filters, sortable columns, detail panel) · data quality · methodology · limitations · report and
reproducibility.

## Data contract (`public/project/`, schema_version `1.0`)

All files are written by `main_analysis.R` §16, and `build_report.R` refreshes them after the PDF is
built. TypeScript types that mirror them exactly are in `lib/project-data.ts`. The loader checks
`schema_version` and that the row counts agree across files.

| File | Content |
| --- | --- |
| `analysis_summary.json` | All results (see below) |
| `qa_report.json` | `status`, `counts {pass, fail, pending, total}`, `dataset {observations, variables, missing_cells, duplicate_rows, duplicate_iso3, aggregate_rows_in_raw, aggregate_rows_in_clean}`, `plausibility_rules[]`, `checks[] {id, category, check, status, detail}` |
| `reproducibility_manifest.json` | `run_started`, `run_finished`, `report_built`, `extraction_date`, `data_year`, `r_version`, `platform`, `os`, `random_seed`, `packages[] {package, version}`, `source {…endpoints, indicators, year_rationale, error_handling}`, `raw_dimensions`, `clean_dimensions`, `figures_generated`, `outputs[] {file, exists, bytes, md5}`, `reproducibility_note` |
| `cleaned_data.json` | The rows of `cleaned_data.csv` (NA → `null`) |
| `cleaned_data.csv`, `data_dictionary.csv` | Offered as downloads |
| `figure1-4.png`, `figure5_regression_diagnostics.png` | The ggplot2 / base-R figures |
| `final_report.pdf` | The report |

## Stack

Next.js 16.2.9 (App Router, Turbopack), React 19.2.4, TypeScript 5.9, Tailwind CSS 4.3,
framer-motion 12 (reveal animations; honours reduced-motion), lenis (smooth scrolling) and
lucide-react (icons). No other dependencies were added to the template.
