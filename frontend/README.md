# Dashboard: interactive presentation layer

A Next.js app, built on the supplied Estate/Next.js UI template, that presents the R practical-exam
analysis. It displays **only** files generated by the R project. It does no statistical calculation
of its own, so it cannot disagree with the report.

```
main_analysis.R / build_report.R  ──writes──▶  frontend/public/project/*  ──read by──▶  this app
```

## Run

```bash
npm install
npm run dev        # development: http://localhost:3000 (re-reads the R outputs on every request)
npm run build      # production: renders the page ONCE from the R outputs (static HTML)
npm run start      # serve the production build
```

**Data flow:** R runs locally → JSON / CSV / PNG / PDF in `public/project/` → `npm run build`
renders a static page → any static host / CDN. The deployed site never needs R. After re-running
the R analysis, rebuild so the static page picks up the new results.

**Missing data:** in development the page lists which R outputs are missing and how to regenerate
them. A production build **fails loudly** instead, so a site can never ship without its data.
Regenerate with `Rscript build_report.R` in the project folder.

## Motion system

All timings live in `lib/motion.ts` (durations micro 150 ms · fast 250 ms · base 450 ms · large
700 ms · cinematic ~1.2 s; easings out / inOut / in; springs ui / soft; stagger caps).

- **L1 global:** hero entrance and parallax, closing scene, reading-progress bar, navbar pill, Lenis.
- **L2 section:** masked headings, figure unmasking, counters, pipeline/methodology rails, sticky
  steps, QA sequence, sensitivity dots.
- **L3 micro:** label-roll buttons, arrow nudges, hover lifts, filters, sort arrows, chevrons.

Primitives (`components/motion/primitives.tsx`): `Reveal` (rise / fade / clip / stagger / scale),
`MaskText`, `StatNumber`. They follow a progressive-enhancement contract: the server HTML is fully
visible; entrance states apply only after an inline script marks `html.js` and the component
hydrates; a CSS fallback reveals everything after 2.5 s if scripts fail.

**Reduced motion** (`prefers-reduced-motion`): `MotionConfig reducedMotion="user"`, no entrance
hiding, counters show final values, no parallax, no blur, no sticky storytelling (stacked layout),
rails shown complete, no scroll-cue pulse; Lenis disables smoothing.

**Dialogs** (figure viewer, country drawer / mobile bottom sheet) use Radix Dialog for focus
trapping, focus return, Escape, scroll lock and ARIA; `data-lenis-prevent` keeps Lenis out.

### Adapted open-source patterns

| Pattern | Source | Licence | Adaptation |
| --- | --- | --- | --- |
| Number Ticker | Magic UI | MIT | → `StatNumber`: server-rendered final value, reduced motion, screen-reader text |
| Blur Fade / Text Animate | Magic UI | MIT | → `Reveal` / `MaskText`: masked line reveal, desktop-only blur |
| InView / TextEffect / AnimatedNumber / ScrollProgress | Motion Primitives | MIT | → viewport triggers, progress bar |

Timeline and sticky-scroll ideas were taken as visual inspiration only; no code was copied from
sources with unclear licensing.

## Data contract (`public/project/`, schema_version `1.0`)

All files are written by `main_analysis.R` §16, and `build_report.R` refreshes them after the PDF is
built. TypeScript types that mirror them exactly are in `lib/project-data.ts`. The loader checks
`schema_version` and that the row counts agree across files.

| File | Content |
| --- | --- |
| `analysis_summary.json` | All results (see below) |
| `qa_report.json` | `status`, `counts {pass, fail, pending, total}`, `dataset {observations, variables, missing_cells, duplicate_rows, duplicate_iso3, aggregate_rows_in_raw, aggregate_rows_in_clean}`, `plausibility_rules[]`, `checks[] {id, category, check, status, detail}` |
| `reproducibility_manifest.json` | `run_started`, `run_finished`, `report_built`, `extraction_date`, `data_year`, `r_version`, `platform`, `os`, `random_seed`, `packages[] {package, version}`, `source {…endpoints, indicators, year_rationale, error_handling}`, `raw_dimensions`, `clean_dimensions`, `figures_generated`, `outputs[] {file, exists, bytes, md5}`, `reproducibility_note` |
| `cleaned_data.json` | The rows of `cleaned_data.csv` (NA → `null`) |
| `cleaned_data.csv`, `data_dictionary.csv` | Offered as downloads |
| `figure1-4.png`, `figure5_regression_diagnostics.png` | The ggplot2 / base-R figures |
| `final_report.pdf` | The report |

`analysis_summary.json` top-level keys:

| Key | Content |
| --- | --- |
| `project` | title, research question, source, source_url, data_year, extraction_date |
| `dataset` | raw_rows/columns, aggregates_removed, duplicates_removed, countries_dropped_missing[], observations, variables, numeric_variables, indicators, indicator_codes, total_missing_cells, pct_missing_cells, missing_by_variable[], cleaning_log[] |
| `key_indicators` | life expectancy mean/median/sd/min/max, GDP per capita mean/median, fertility mean/median, pct_missing_cells |
| `descriptive_statistics[]` | variable, n, missing, mean, median, min, max, sd |
| `group_analysis` | by_region[], by_income[] |
| `anova` | f_statistic, df_between, df_within, p_value, eta_squared, welch_f, welch_df[], welch_p, welch_note, region_sd[], interpretation |
| `correlation` | pearson_raw, pearson_log, pearson_log_ci[], pearson_log_p, spearman, n, strength, table[], interpretation |
| `regression` | formula, method, why_log, n, coefficients[] {term, estimate, std_error, t_value, p_value, ci_low, ci_high}, r_squared, adj_r_squared, residual_se, f_statistic, f_p_value, interpretation, diagnostics {cooks_threshold, leverage_threshold, influential[], n_high_leverage, large_residuals[], shapiro_w, shapiro_p, residual_skewness, curvature_p, notes[]} |
| `outliers` | method, variables[] {variable, q1, q3, iqr, lower_bound, upper_bound, n_outliers, n_low, n_high, countries[]}, total_flagged, life_expectancy_history[] |
| `sensitivity` | scenarios[] {scenario, n, excluded, pearson_r_log_gdp, spearman_rho, slope, r_squared, strength}, conclusion |
| `figures[]` | id, number, file, required, type, title, purpose, interpretation, file_exists |
| `section_a` | students[], score_statistics[], programme_averages[], overall_average, above_average[] |
| `limitations[]` | title, text |
| `automated_summary[]` | generated sentences |
| `validation` | status, checks_total, checks_passed, checks_failed, checks_pending |

## Stack

Next.js 16.2.9 (App Router, Turbopack), React 19.2.4, TypeScript 5.9, Tailwind CSS 4.3,
framer-motion 12 (the only animation engine), lenis (smooth scrolling), lucide-react (icons) and
@radix-ui/react-dialog (accessible dialogs, added in V2.1 - the only dependency added to the template).
